# NOS Neovim

This is my migration from Packer.nvim to Lazy.nvim. I was aiming for something light, but included a few more plugins than I would normally run on a daily basis. Most of these have been commented out in the main `lazy.lua` configuration file, so as it stands the setup is still fairly lightweight and minimal.

## Current Setup

* fzf-lua
* lualine
* neogit
* ccc (color picker)
* gitsigns

## Installed but Disabled
